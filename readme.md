# Master Advances CSS and JavaScript Animations

This uses Python web server to serve the samples.

## Features
- Automatically opens in the browser.
- Displays a directory listing with clickable links.
- Ignores certain files (`.git`, `.gitignore`, `.history`, `server.py`).

## Requirements
- Python 3.x

## Installation
1. Clone or download this script.
2. Run the server with:
   ```sh
   python server.py
